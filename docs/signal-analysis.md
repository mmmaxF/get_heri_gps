# GPS/MOD信号の解析記録

SDI音声に含まれる位置情報信号を特定した際の記録です。

## 観測結果

NMEAはSDIに載っていませんでした。

約1200 Hzと1800 Hzの周期的な信号が確認できました。

- 1200 Hz: 0
- 1800 Hz: 1

周波数変調の復調前の信号である可能性が高いと判断しました。

SDI音声では、一般的に音声サンプリング周波数は48 kHzが標準です。

- 600 bps: 意味のあるフレームにならない
- 2400 bps: 意味のあるフレームにならない
- 1200 bps: HDLCの `0x7e` が現れ、CRCが一致し、`:MOD` が得られる

```text
0x7e ... データ本体 ... 0x7e
```

## AX.25としての解析

AX.25は無線パケット通信で使われる通信形式です。HDLCフレームの中身は、おおむね次の順番です。

```text
宛先
送信元
制御情報
プロトコルID
情報本体
CRC
```

今回の復調データは次のように読めました。

```text
宛先    : CQ
送信元  : MIKE
control : 0x03
PID     : 0xf0
info    : :MOD...
CRC     : OK
```
